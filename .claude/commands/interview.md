# /interview — Voice-first adaptive technical interview

Read `skills/ai-interview/SKILL.md`, `skills/ai-interview/references/voice-first-studio.md` and `skills/ai-interview/references/career-workflow.md`. Start the local studio only for an explicit candidate request, using `python3 skills/ai-interview/scripts/career.py interview --doctor` before offering an authenticated local UI. The candidate uploads a CV, chooses role, optional saved JD, source-verified research refresh and memory consent, then starts the session. Spoken questions and microphone answers are the default except Coding. Only confirmed transcripts are graded. Preserve strong baselines, fair rebuttal, and reference solutions after review. Do not mistake a stale study timestamp for forgotten knowledge; do not claim network-fetched 'latest' without a dated source.

Optional: If the candidate explicitly asks to use the independently installed VoiceStudio audio engine, read `skills/ai-interview/references/voicestudio-backend.md`. First run `python3 skills/ai-interview/scripts/career.py interview --doctor --voicestudio` (no microphone access). Do not install an external app, models, or `websockets` without permission. Once prerequisites and separate-service consent are satisfied, start `python3 skills/ai-interview/scripts/career.py interview --without-stt --voicestudio`; the page offers VoiceStudio TTS/streaming and keeps browser/Whisper/typing fallback. Never claim a completed real-device microphone test based only on simulated interface checks.
