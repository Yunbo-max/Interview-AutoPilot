# /rank — Explainable shortlist, not hiring predictions

Read `skills/ai-interview/references/career-workflow.md`. Run `python3 skills/ai-interview/scripts/career.py rank` (optionally `--role <role>`). Explain which job-description skills appear in the candidate-provided CV, missing or uncertain evidence, and why a role appears on the shortlist. Scores are heuristic relevance only. Show posting source URLs, remind the candidate to confirm live status, and let the candidate choose which JD to rehearse. Never perform an application.
