# AI Interview

**不是替你写简历，而是让你为自己的解释和方案辩护。**

[English](README.md) · [Skill 入口](skills/ai-interview/SKILL.md) · [完整设计](docs/DESIGN.md) · [验收标准](docs/ACCEPTANCE.md)

## 当前交付是什么

`0.1.0` 是完整的 **Skill 设计包**：主入口、13 份操作规则、结构化数据契约、编码和数学参考题、交锋示例、离线检查与行为验收案例。

**它不是已经做完的语音网站。** 麦克风、实时语音、声学分析、安全代码执行、一小时自动计时和断线恢复，需要宿主程序实现接口并通过测试。不能把写在 Skill 里的功能描述当成已经运行的功能。

具备技能加载能力的 Agent 可以按规则开展文字模拟面试；具体宿主执行效果仍需实测。普通聊天没有持续计时器时，60 分钟只是由你掌控的目标时长，不会谎称后台一直运行。

## 面试怎样进行

你回答一句，面试官根据你的实际回答追问一句。对方可以质疑因果解释、要求说明输入输出、提出反例、检查复杂度和推导条件；当你的反驳成立时，必须撤回质疑，而不是为了高压一直抬杠。

简历与科研部分覆盖个人贡献、技术机制、数学假设、公平基线、指标口径、实验归因和失败条件。编码题有参考实现、边界测试和复杂度要求；数学题有条件、推导、有效替代解法及变式。严格模式不提前泄露答案，主动要提示或答案会记录辅助程度。

语音部分把四件事分开：录音质量、语速停顿等声学观察、表达结构、内容正确性。没有原音频就不判断语调；转写把 n log n 听成 n 平方时，先更正记录并撤回相关误判。摄像头可选，不评表情、眼神、人格、诚实度或录用概率。

## 默认一小时结构

开场 5 分钟，简历/科研交锋 20 分钟，编码 20 分钟，数学 10 分钟，反问收尾 5 分钟。详细复盘放在计时之外。可以按岗位调整；暂停、设备故障和阻塞式服务等待不算候选人耗时，正常思考和写代码算在约定时间内。

严格、教学、弱项复练三种模式与压力风格分开。可以说“暂停”“继续”“识别错了”“我不同意”“给提示”“给答案”“结束”来控制。

## 在 Codex 中使用

按 [英文 README 的安装步骤](README.md#install-in-codex)复制完整的 `skills/ai-interview/` 文件夹，然后输入：

```text
$ai-interview 根据我提供的简历开始模拟面试。
目标 60 分钟，使用中文，高强度技术追问，包含科研、coding 和数学。
先检查当前宿主的真实能力，不提前给参考答案。
```

这不会自动接通电脑麦克风；麦克风和云端处理需要额外授权及可运行的适配器。插件描述文件已提供，但不表示已经安装到你的账号或上架目录。

## 验证与隐私

离线测试只核对包结构、契约、示例和参考代码，不代表完成了真实 Agent 对抗测试或一小时语音测试。行为场景明确保留 `not_run`，不把虚构对话当作实测。

真实简历、音视频、回答代码和面试评分不能默认上传到这个公开仓库。没有安全隔离器，不执行候选人代码；没有可靠时钟，不编造用时；没有音频，不编造语速或语调数据。
